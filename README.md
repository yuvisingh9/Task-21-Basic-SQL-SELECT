# Task 21 – Basic SQL SELECT

**Topic:** Basic SQL SELECT

## Project Overview
This project demonstrates the fundamentals of SQL data retrieval using SELECT, WHERE, and ORDER BY statements.

The project uses a sample customer dataset containing 12 records to practice SQL queries and understand data filtering and sorting.

## Objectives
- Understand basic SQL SELECT statements.
- Retrieve specific columns from a database.
- Filter records using WHERE.
- Sort records using ORDER BY.
- Build practical SQL fundamentals.

## Tools Used
- MySQL
- PostgreSQL
- SQL

## Dataset Description

The project includes a customer dataset with the following columns:

| Column | Description |
|---|---|
| customer_id | Unique customer ID |
| customer_name | Customer or company name |
| city | Customer city |
| country | Customer country |
| contact_title | Contact person's job title |
